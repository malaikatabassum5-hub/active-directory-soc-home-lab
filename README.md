# Active Directory SOC Home Lab

## Project Overview

This project documents my practical learning experience with Active Directory in a virtual lab environment.

The purpose of this lab is to understand Windows domain environments, user management, and basic security monitoring.

## Lab Environment

- **Virtualization:** VMware
- **Server:** Windows Server 2019
- **Client:** Windows 10
- **Directory Service:** Active Directory

## What I Worked On

- Setting up a Windows Server environment.
- Exploring Active Directory.
- Creating and managing domain users.
- Connecting a Windows client to the domain.
- Exploring Windows security event logs.
- Learning basic security monitoring concepts.

## Key Learning Outcomes

- Active Directory fundamentals.
- Windows Server administration basics.
- Domain user and group management.
- Understanding Windows security events.
- Introduction to SOC monitoring.
